## 1. [HAUTE] Bouton « Scanner les dossiers à 0 » : n'existe pas sous ce nom

**Clés** : `inventory.scan` (FR.lang:51 / US.lang:51) vs `inventory.n_unknown_folders`
(FR.lang:73 / US.lang:73)

**Texte actuel** :
- Bouton réel : `"Scanner les dossiers à mesurer"` / `"Scan the folders to measure"`
- Message qui le désigne : `"… bouton « Scanner les dossiers à 0 » pour les mesurer."` /
  `"… use « Scan zero-size folders » to measure them."`

**Problème** : le message renvoie vers un bouton dont le libellé n'est plus celui-là
(renommage non répercuté). L'utilisateur cherche un bouton qui n'existe pas.

**Réécriture proposée** :
FR : `"{n} dossier(s) sans taille reportée — bouton « Scanner les dossiers à mesurer » pour les mesurer."`
US : `"{n} folder(s) with no reported size — use « Scan the folders to measure » to measure them."`

## 2. [HAUTE] Bouton « Calculer la taille » : le bouton réel s'appelle « Remesurer »

**Clés** : `import.compute_size` (FR/US.lang:252) vs `import.sizes_required_body`
(FR/US.lang:276) et `import.size_cancelled_msg` (FR/US.lang:391)

**Texte actuel** :
- Bouton réel : `"Remesurer"` / `"Re-measure"`
- Deux messages : `"Cliquez sur « Calculer la taille » avant de générer…"` et
  `"relancez « Calculer la taille » pour les compléter…"`

**Problème** : même défaut que le finding 1. Le bloc d'aide (FR.lang:771) dit
correctement « Remesurer » — ce sont les deux messages d'erreur qui sont restés en arrière,
c'est-à-dire précisément les textes qu'on lit quand on est bloqué.

**Réécriture proposée** :
FR : `« Remesurer »` dans les deux messages.
US : `« Re-measure »` dans les deux messages.

## 3. [HAUTE] « onglet Import » / « Import tab » : vocabulaire d'avant le passage à « étape » (v3)

**Clés** : `inventory.compound_summary` (FR/US:113), `import.no_inventory_read` (302),
`detail.tasks2_hint` (216), `detail.export_tasks2_msg` (221), `profiles.set_default_msg`
(445), `topbar.language_lose_work` (458), `options.recursive_help` (FR:514/US:513), et
trois blocs d'aide FR.lang:879, 1043, 1055.

**Problème** : le reste de l'application dit systématiquement « étape « 2. Import des
sources » » (cf. `import.select_case_first`, `import.select_case_target`). Ces neuf chaînes
disent encore « l'onglet Import » — un nom qui ne correspond ni au libellé de l'onglet
(`tabs.import` = « 2. Import ») ni à celui de l'étape (`step.sources`). ⚠ Fait notable :
les **trois blocs d'aide US (US.lang:875, 1035, 1047) disent déjà « the “2. Import
sources” step »** — la version anglaise a été corrigée à cet endroit, pas la française, ni
les chaînes courtes des deux langues.

**Réécriture proposée** (motif à appliquer à toutes les occurrences) :
FR : `"l'onglet Import"` → `"l'étape « 2. Import des sources »"` ; `"(onglet 1)"` →
`"(étape « 1. Le cas »)"`.
US : `"the Import tab"` → `"the “2. Import sources” step"` ; `"(tab 1)"` →
`"(step “1. The case”)"`.

## 4. [MOYENNE] US.lang mélange orthographe britannique et américaine

**Clés** : britannique dans `import.reason_unknown` (US:411, « recognised »), aide US:847
(« colour-coded ») et US:935 (« colours »), `import.summarize` (333), `validation.no_sources`
(376), `profiles.set_default_msg` (445), `import.clear_confirm` (556), `help.fig_step2_sub`
(691), `options.intellacmd_debug_help` (626), `import.validate_busy` (356) et l'aide
(US:755, 759, 1047) — américain dans `detail.optim_folder` (« Optimization »),
`inventory.autolicense` (« license »), `opt.analyseParagraphs` (« Analyze paragraphs »),
`import.validate_head` (353), `import.validate_run_analyzed` (359),
`import.validate_start_log` (361), `import.validate_summary_log` (362).

**Problème** : le cas le plus visible est `import.validate_busy` (« analysing the logs… »)
et `import.validate_start_log` (« analyzing logs… ») : deux messages presque jumeaux à
cinq lignes d'écart, chacun avec sa propre orthographe.

**Réécriture proposée** : standardiser sur l'américain (déjà majoritaire) —
`recognised→recognized`, `colour(s)→color(s)`, et toutes les formes
`analyse/analysed/analysing→analyze/analyzed/analyzing` dans les clés listées.
⚠ Ne PAS toucher à `opt.analyseParagraphs` : la **clé** reflète le nom d'option
d'IntellaCmd (orthographe GB figée dans le contrat public de Vound) ; seule sa valeur
affichée est concernée, et elle est déjà en américain.

## 5. [MOYENNE] Aide FR et US ne décrivent pas le même contenu pour « Tout vider »

**Clés** : bloc d'aide FR.lang:771 vs US.lang:761-763

**Texte actuel** :
- FR : `"« Tout vider » repart de zéro : il efface le tableau ET les chemins collés au-dessus. Le menu « Plus ▾ » propose « Vider la liste », qui ne vide que le tableau."`
- US : `"“Clear the list” removes every source at once. The paths pasted above are kept."`

**Problème** : la version FR documente les DEUX boutons et leur différence ; la version US
ne documente que « Clear the list » et passe sous silence « Clear all » (qui existe :
`import.clear_all`). Un lecteur anglophone n'apprend pas que ce bouton existe.

**Réécriture proposée (US)** : `"“Clear all” starts from scratch: it clears the table AND
the paths pasted above. The “More ▾” menu offers “Clear the list”, which only clears the
table."`

## 6. [MOYENNE] `ui_help.py` : repli d'urgence figé en français

**Référence** : `ui_help.py:56-62` (`_DEFAULT_CONTENT`)

**Problème** : ce contenu s'affiche quand `i18n.help_content()` échoue — donc quand le
système de traduction est en panne, ce qui explique qu'il ne passe pas par `i18n.t()`.
Résultat : un utilisateur ayant choisi l'anglais voit un message d'erreur entièrement en
français, titre compris.

**Réécriture proposée** : rendre ce repli **bilingue**, puisqu'il ne peut pas dépendre du
système qui a failli — `"{APP} — Help / Aide"`, puis chaque phrase dans les deux langues.

## 7. [BASSE] Jargon technique dans deux messages rares

**Clés** : `task_builder.err_not_array` (FR/US.lang:393), `inventory.export_tasks_msg`
(FR/US.lang:103)

**Texte actuel** : `"Les tâches doivent être un tableau JSON (format exporté par Intella)."`
et `"1 objet = 1 tâche logique (UUID par source fusionnés par signature)."`

**Problème** : « tableau JSON » et « UUID … fusionnés par signature » sont du vocabulaire
de développeur — contrairement à `case.xml` ou aux formats d'image, ce ne sont pas des
objets que l'enquêteur manipule.

**Réécriture proposée** :
FR : `"Le fichier de tâches doit contenir une liste de tâches (le format exporté par Intella)."`
et `"1 export = 1 tâche unique : les tâches identiques appliquées à plusieurs sources sont regroupées en une seule ligne."`
US : équivalents.

## Remarques mineures

- `files.missing` : FR `"absent"` sans parenthèses vs US `"(missing)"` avec — cosmétique.
- `detail.email_threading` (FR.lang:211) : « Email Threading effectué » garde le terme
  anglais d'Intella — probablement voulu ; à vérifier si l'UI d'Intella a un équivalent FR.
- Aucune espace insécable devant `:` `;` `?` `»` dans tout FR.lang — choix systématique,
  pas une incohérence entre chaînes.
- `help.fig_first` US : « give this one » est familier au regard du registre de l'aide ;
  « indicate this one » serait plus homogène.

## Signalé pour mémoire

- « include » / « exclude » non traduits dans le schéma `_fig_filtre` (`ui_help.py:259-264`)
  : cohérent, ce sont des valeurs techniques d'Intella citées telles quelles ailleurs.
- Le profil « défaut », les arguments IntellaCmd, les formats d'image (E01, AD1) et les
  types MIME : non comptés, conformément au périmètre.

## Ce qui est bien écrit

- L'explication du mode `include`/`exclude` (`profiles.filter_mode_tip`, bloc d'aide « Le
  mode : à lire avant tout le reste ») anticipe explicitement le contresens le plus probable
  avant qu'il ne se produise — un modèle du genre.
- Le code couleur des réglages repris par un profil (bleu / noir / rouge) est expliqué
  simplement, avec pour chaque couleur une phrase qui dit quoi faire.
- Registre globalement homogène (vouvoiement, infinitif pour les boutons, impératif pour
  les instructions) sur l'essentiel des ~730 chaînes.
- La structure de `ui_help.py` (sommaire, recherche, largeur de lecture plafonnée) sert
  bien l'objectif de lisibilité annoncé dans son propre en-tête.
